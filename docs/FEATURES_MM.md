# လုပ်ဆောင်ချက်များ စာရင်း (Features List - Myanmar Language)

## ၁။ စနစ်စီမံခန့်ခွဲသူ လုပ်ဆောင်ချက်များ - Admin Dashboard (smart-parking-management)

### ၁.၁ အကောင့်ဝင်ရောက်ခြင်းနှင့် လုပ်ပိုင်ခွင့် စိစစ်ခြင်း (Authentication)
- [ ] အကောင့်ဝင်ရောက်ခြင်း (Login)
  - [ ] အီးမေးလ်နှင့် စကားဝှက် မှန်ကန်မှု စစ်ဆေးခြင်း
  - [ ] စနစ်စီမံခန့်ခွဲသူ (`ADMIN`) ရာထူး ဟုတ်မဟုတ် စစ်ဆေးခြင်း
  - [ ] အချက်အလက် မမှန်ပါက အမှားပြစာတို ဖော်ပြခြင်း
  - [ ] အကောင့်ဝင်ရောက်မှု အောင်မြင်ပါက `/admin/dashboard` သို့ ပို့ဆောင်ပေးခြင်း
  - [ ] JWT တိုကင် သိမ်းဆည်းခြင်းနှင့် Admin Profile ဒေတာ ရယူခြင်း
- [ ] အကောင့်လုံခြုံရေး စနစ် (Auth Guard)
  - [ ] အကောင့်မဝင်ထားသော သုံးစွဲသူများကို Login စာမျက်နှာသို့ ပြန်လည်ညွှန်းပို့ခြင်း
  - [ ] Admin မဟုတ်သော အခြားရာထူးများအား ဝင်ရောက်ခွင့် ပိတ်ပင်ခြင်း
  - [ ] အကောင့်ထွက်ပါက တိုကင် ဖျက်ဆီး၍ Login စာမျက်နှာသို့ ပြန်လည်ပို့ဆောင်ခြင်း

### ၁.၂ ဒက်ရှ်ဘုတ် ပုံစံ (Dashboard Layout)
- [ ] ဘေးတိုက် မီနူး (Sidebar)
  - [ ] ခေါက်/ပြန်ဖြန့်နိုင်သော ဘေးတိုက်မီနူး
  - [ ] စနစ် လိုဂိုနှင့် Admin ခေါင်းစဉ် ဖော်ပြမှု
  - [ ] Admin မီနူးများ (Dashboard, Users, Packages, Subscriptions, Wallet Settings)
  - [ ] လက်ရှိ ရောက်ရှိနေသော မီနူးအား ပေါ်လွင်အောင် အရောင်ပြောင်းဖော်ပြခြင်း
  - [ ] သုံးစွဲသူ အချက်အလက် အကျဉ်းနှင့် အကောင့်ထွက်ရန် ခလုတ်
- [ ] ထိပ်စီးဘား (Header)
  - [ ] လက်ရှိ စာမျက်နှာ ခေါင်းစဉ်နှင့် လမ်းကြောင်းပြ လင့်ခ်များ (Breadcrumb)
  - [ ] သုံးစွဲသူ ပရိုဖိုင် ပုံနှင့် အမြန်ဆက်တင် ဒရော့ဒေါင်းမီနူး

### ၁.၃ စနစ်စီမံခန့်ခွဲသူ ဒက်ရှ်ဘုတ် စာမျက်နှာ (/admin/dashboard)
- [ ] စနစ်တစ်ခုလုံးဆိုင်ရာ အချက်အလက် ကတ်များ (Stat Cards)
  - [ ] စုစုပေါင်း ယာဉ်ရပ်နားစခန်း ပိုင်ရှင် အရေအတွက် (Total Owners)
  - [ ] စုစုပေါင်း ဖွင့်လှစ်ထားသော ယာဉ်ရပ်နားစခန်း အရေအတွက် (Active Lots)
  - [ ] စနစ်တစ်ခုလုံးတွင် လက်ရှိ ရပ်နားထားသော ယာဉ်အရေအတွက် (Active Sessions)
  - [ ] စနစ်၏ စုစုပေါင်း ဝင်ငွေ (Total Revenue in MMK)
- [ ] ဇယားများနှင့် သုံးသပ်ချက်များ (Analytics & Charts)
  - [ ] ဝန်ဆောင်ခ ရရှိမှု လစဉ် အခြေပြ ဇယား (Subscription Earnings Chart)
  - [ ] စခန်းများ၏ ယာဉ်ရပ်နားနိုင်မှု ရာခိုင်နှုန်း (Occupancy Rate)
  - [ ] အသုံးပြုနေသော နှင့် ပိတ်ထားသော စခန်းများ အချိုးအစား
- [ ] အမြန် လုပ်ဆောင်ချက်များ (Quick Actions)
  - [ ] သုံးစွဲသူများ စီမံခန့်ခွဲရန် → `/admin/users`
  - [ ] ဝန်ဆောင်မှု ပက်ကေ့ဂျ်များ ပြင်ဆင်ရန် → `/admin/packages`
  - [ ] ပိုင်ရှင်များ၏ ဝန်ဆောင်မှု သက်တမ်း ကြည့်ရန် → `/admin/subscriptions`

### ၁.၄ သုံးစွဲသူများ စီမံခန့်ခွဲခြင်း (/admin/users)
- [ ] သုံးစွဲသူ စာရင်း (Users List)
  - [ ] သုံးစွဲသူများ ဇယား (အမည်၊ အီးမေးလ်၊ ရာထူး၊ ဖုန်းနံပါတ်၊ အီးမေးလ် အတည်ပြုပြီးမှု၊ အကောင့် အခြေအနေ)
  - [ ] အမည် သို့မဟုတ် အီးမေးလ်ဖြင့် ရှာဖွေနိုင်ခြင်း (Search)
  - [ ] ရာထူးအလိုက် သီးသန့် စစ်ထုတ်နိုင်ခြင်း (`ALL`, `ADMIN`, `OWNER`, `STAFF`, `CUSTOMER`)
  - [ ] စာမျက်နှာ ခွဲခြားကြည့်ရှုနိုင်ခြင်း (Pagination) နှင့် ကော်လံအလိုက် စီနိုင်ခြင်း
- [ ] အကောင့် ဆိုင်ရာ လုပ်ဆောင်ချက်များ
  - [ ] အကောင့် ပိတ်/ဖွင့် ပြုလုပ်နိုင်ခြင်း (Activate / Deactivate Toggle)
  - [ ] အီးမေးလ် အတည်ပြုပြီး/မပြီး အခြေအနေ စစ်ဆေးနိုင်ခြင်း
  - [ ] သုံးစွဲသူ၏ အသေးစိတ် အချက်အလက် ပေါ့ပ်အပ် ကြည့်ရှုနိုင်ခြင်း

### ၁.၅ ဝန်ဆောင်မှု ပက်ကေ့ဂျ်များ စီမံခန့်ခွဲခြင်း (/admin/packages)
- [ ] ပက်ကေ့ဂျ် စာရင်းများ
  - [ ] ဝန်ဆောင်မှု အဆင့်များ (Basic, Pro, Enterprise)
  - [ ] ပက်ကေ့ဂျ် အသေးစိတ် (စျေးနှုန်း MMK၊ သက်တမ်း ရက်၊ စခန်း အများဆုံး အရေအတွက် `max_lots`၊ ဝန်ထမ်း အများဆုံး အရေအတွက် `max_staff`)
  - [ ] အသုံးပြုနိုင်မှု အခြေအနေ ဘေ့ဂျ် (Active / Inactive)
- [ ] ပက်ကေ့ဂျ်သစ် ဖန်တီးခြင်း (/admin/packages/create)
  - [ ] အမည်၊ ဖော်ပြချက်၊ စျေးနှုန်း၊ သက်တမ်း၊ စခန်း ကန့်သတ်ချက်၊ ဝန်ထမ်း ကန့်သတ်ချက် ဖြည့်သွင်းခြင်း
  - [ ] အချက်အလက် မှန်ကန်မှု စစ်ဆေးခြင်း
- [ ] ပက်ကေ့ဂျ် ပြင်ဆင်ခြင်း (/:id/edit)
  - [ ] မူလ အချက်အလက်များ ဖြည့်သွင်းထားပြီး ပြန်လည်ပြင်ဆင်နိုင်ခြင်း
- [ ] အသုံးပြုနိုင်မှု အခြေအနေ အဖွင့်/အပိတ် ပြုလုပ်ခြင်း
  - [ ] ပိုင်ရှင်များ ဝယ်ယူနိုင်ရန် ပက်ကေ့ဂျ် ဖွင့်/ပိတ် ပြုလုပ်ခြင်း

### ၁.၆ ပိုင်ရှင်များ၏ ဝန်ဆောင်မှု သက်တမ်း စီမံခန့်ခွဲခြင်း (/admin/subscriptions)
- [ ] ဝန်ဆောင်မှု သက်တမ်း စာရင်းများ
  - [ ] ပိုင်ရှင်များ ဝယ်ယူထားသော ပက်ကေ့ဂျ်များ ဇယား (ပိုင်ရှင်အမည်၊ ကုမ္ပဏီအမည်၊ ပက်ကေ့ဂျ်အမည်၊ အခြေအနေ၊ ကျသင့်ငွေ၊ စတင်ချိန်/ကုန်ဆုံးချိန်)
  - [ ] အခြေအနေအလိုက် စစ်ထုတ်ခြင်း (`ACTIVE`, `PENDING`, `EXPIRED`, `CANCELLED`)
  - [ ] ပိုင်ရှင် အီးမေးလ် သို့မဟုတ် ကုမ္ပဏီအမည်ဖြင့် ရှာဖွေနိုင်ခြင်း
- [ ] ဝန်ဆောင်မှု သက်တမ်း ဆိုင်ရာ လုပ်ဆောင်ချက်များ
  - [ ] ဝန်ဆောင်မှု သက်တမ်းအား ကိုယ်တိုင် အတည်ပြုပေးနိုင်ခြင်း (Manual Activation Button)
  - [ ] သက်တမ်း ပယ်ဖျက်ခြင်း သို့မဟုတ် တိုးမြှင့်ပေးခြင်း

### ၁.၇ စနစ်၏ ဒစ်ဂျစ်တယ် ပိုက်ဆံအိတ် ပြင်ဆင်ခြင်း (/admin/wallet)
- [ ] ပိုက်ဆံအိတ် ဆက်တင် ပုံစံ
  - [ ] Digital Wallet API Key (`X-API-Key`) ဖြည့်သွင်းခြင်း
  - [ ] စနစ်၏ ပိုက်ဆံအိတ် ဖုန်းနံပါတ် ဖြည့်သွင်းခြင်း
  - [ ] ဒစ်ဂျစ်တယ် ပိုက်ဆံအိတ် စနစ်နှင့် ချိတ်ဆက်မှု အခြေအနေ စမ်းသပ်ခြင်း

### ၁.၈ ပရိုဖိုင်နှင့် ဆက်တင်များ (/admin/profile)
- [ ] ပရိုဖိုင် အချက်အလက် ကြည့်ရှုခြင်း (အမည်၊ အီးမေးလ်၊ ဖုန်းနံပါတ်၊ ရာထူး)
- [ ] စကားဝှက် ပြောင်းလဲခြင်း (လက်ရှိ စကားဝှက် + စကားဝှက်သစ် အတည်ပြုခြင်း)

## ၂။ ယာဉ်ရပ်နားစခန်း ပိုင်ရှင် လုပ်ဆောင်ချက်များ - Owner Dashboard (smart-parking-management)

### ၂.၁ အကောင့်ဝင်ခြင်းနှင့် ဝန်ဆောင်မှု ကန့်သတ်ချက်များ
- [ ] အကောင့်ဝင်ရောက်ခြင်း (Login - `OWNER` ရာထူး)
- [ ] ဝန်ဆောင်မှု ကန့်သတ်ချက် စစ်ဆေးခြင်း (Quota Guard)
  - [ ] အသုံးပြုနိုင်သော Subscription သက်တမ်း ရှိမရှိ စစ်ဆေးခြင်း
  - [ ] စခန်းအသစ် ဆောက်လုပ်ပါက ဝယ်ယူထားသော ပက်ကေ့ဂျ်၏ စခန်းအရေအတွက် ကန့်သတ်ချက် (`max_lots`) စစ်ဆေးခြင်း
  - [ ] ဝန်ထမ်းအသစ် ခန့်အပ်ပါက ဝန်ထမ်းအရေအတွက် ကန့်သတ်ချက် (`max_staff`) စစ်ဆေးခြင်း

### ၂.၂ ပိုင်ရှင် ဒက်ရှ်ဘုတ် ပုံစံ
- [ ] ဘေးတိုက် မီနူး (Sidebar)
  - [ ] ပိုင်ရှင်၏ ကုမ္ပဏီအမည် ဖော်ပြမှု
  - [ ] မီနူးများ (Dashboard, Parking Lots, Staff, Subscription, Wallet Setup)
  - [ ] လက်ရှိ အသုံးပြုနေသော ပက်ကေ့ဂျ် အဆင့် ဘေ့ဂျ် (ဥပမာ - *Pro Plan*)
- [ ] ထိပ်စီးဘား (Header)
  - [ ] ယာဉ်ရပ်နားစခန်း ရွေးချယ်နိုင်သော ဒရော့ဒေါင်း
  - [ ] ပိုင်ရှင် ပရိုဖိုင် ပုံ

### ၂.၃ ပိုင်ရှင် ဒက်ရှ်ဘုတ် စာမျက်နှာ (/owner/dashboard)
- [ ] ဝင်ငွေနှင့် ယာဉ်ရပ်နားမှု စာရင်းင်း ကတ်များ
  - [ ] စုစုပေါင်း ရရှိထားသော ဝင်ငွေ (Total Revenue in MMK)
  - [ ] ဖွင့်လှစ်ထားသော စခန်း အရေအတွက်
  - [ ] ခန့်အပ်ထားသော ဝန်ထမ်း အရေအတွက်
  - [ ] လက်ရှိ ယာဉ်ရပ်နားထားမှု ရာခိုင်နှုန်း (Occupancy %)
- [ ] ဇယားများနှင့် သုံးသပ်ချက်များ
  - [ ] ဝင်ငွေ အခြေပြ ဇယား (နေ့စဉ် / တစ်ပတ်စာ / လစဉ်)
  - [ ] စခန်းများအလိုက် ယာဉ်ရပ်နားမှု နှိုင်းယှဉ်ချက် ဇယား
- [ ] လတ်တလော ယာဉ်ရပ်နားမှု စာရင်းများ (Recent Sessions Table)

### ၂.၄ ယာဉ်ရပ်နားစခန်းများ စီမံခန့်ခွဲခြင်း (/owner/lots)
- [ ] ယာဉ်ရပ်နားစခန်း စာရင်း (Lots List)
  - [ ] စခန်းအမည်၊ အမျိုးအစား (`PUBLIC`/`PRIVATE`)၊ တစ်နာရီ ကျသင့်ငွေ၊ အထပ် အရေအတွက်၊ နေရာ အရေအတွက်၊ အခြေအနေ
  - [ ] Google Maps ဖြင့် တည်နေရာ ကြည့်ရှုနိုင်သော ခလုတ်
- [ ] ယာဉ်ရပ်နားစခန်းအသစ် ဖန်တီးခြင်း (/owner/lots/create)
  - [ ] စခန်းအမည်၊ အမျိုးအစား၊ တစ်နာရီ ကျသင့်ငွေ (MMK) ဖြည့်သွင်းခြင်း
  - [ ] Google Maps URL နှင့် မြေပုံ တည်နေရာ GPS Coordinates (Latitude/Longitude) ဖြည့်သွင်းခြင်း
  - [ ] ပက်ကေ့ဂျ် ကန့်သတ်ချက် (`max_lots`) စစ်ဆေးခြင်း
- [ ] စခန်း အချက်အလက် ပြင်ဆင်ခြင်း (/:id/edit)
- [ ] စခန်း အသုံးပြုနိုင်မှု အခြေအနေ အဖွင့်/အပိတ် ပြုလုပ်ခြင်း

### ၂.၅ အထပ်နှင့် ယာဉ်ရပ်နားနေရာ 2D/3D ဒီဇိုင်းစနစ် (/owner/lots/:id/floors)
- [ ] အထပ်များ စီမံခန့်ခွဲခြင်း (Floors)
  - [ ] အထပ်အသစ် ထည့်သွင်းခြင်း (ဥပမာ - မြေညီထပ်၊ ပထမထပ်၊ မြေအောက်ထပ် B1)
  - [ ] အထပ် အမည်များ ပြင်ဆင်ခြင်း
- [ ] ယာဉ်ရပ်နားနေရာ ဒီဇိုင်းရေးဆွဲခြင်း (Slots)
  - [ ] နေရာအသစ် ထည့်သွင်းခြင်း (နေရာနံပါတ်၊ အပိုင်းအခြား အမည် ဥပမာ - Section A၊ တည်နေရာ GPS Coordinates)
  - [ ] နေရာများ အများအပြား တစ်ပြိုင်နက် ဖန်တီးခြင်း (Bulk Generation)
  - [ ] လက်ရှိ နေရာ လွတ်/မလွတ် အရောင်ဖြင့် ပြသခြင်း (🟢 လွတ် / 🔴 ပြည့်)
- [ ] ရုပ်ထွက်မြင်ကွင်း ကြည့်ရှုခြင်း (Visual Layout Inspector)
  - [ ] 2D Grid ကြည့်ရှုမှု မြင်ကွင်း
  - [ ] 3D Interactive မြင်ကွင်း သို့ ပြောင်းလဲကြည့်ရှုနိုင်ခြင်း

### ၂.၆ ဝန်ထမ်းများ စီမံခန့်ခွဲခြင်း (/owner/staff)
- [ ] ဝန်ထမ်း စာရင်း (Staff List)
  - [ ] ခန့်အပ်ထားသော ဝန်ထမ်းများ ဇယား (အမည်၊ အီးမေးလ်၊ ဖုန်းနံပါတ်၊ တာဝန်ကျ စခန်း၊ စတင်ရက်)
- [ ] ဝန်ထမ်းအသစ် ခန့်အပ်ခြင်း (/owner/staff/create)
  - [ ] အမည်၊ အီးမေးလ်၊ စကားဝှက်၊ ဖုန်းနံပါတ် ဖြည့်သွင်းခြင်း
  - [ ] တာဝန်ကျမည့် ယာဉ်ရပ်နားစခန်း ရွေးချယ်ပေးခြင်း
  - [ ] ပက်ကေ့ဂျ် ကန့်သတ်ချက် (`max_staff`) စစ်ဆေးခြင်း
- [ ] ဝန်ထမ်း အကောင့် ဖျက်ဆီးခြင်း သို့မဟုတ် တာဝန်ကျ စခန်း ပြောင်းလဲခြင်း

### ၂.၇ ဝန်ဆောင်မှု ပက်ကေ့ဂျ် ဝယ်ယူခြင်း (/owner/subscription)
- [ ] လက်ရှိ အသုံးပြုနေသော ပက်ကေ့ဂျ် ကတ်
  - [ ] ပက်ကေ့ဂျ် အမည်၊ အခြေအနေ (`ACTIVE`)၊ စတင်ရက်၊ ကုန်ဆုံးရက်
  - [ ] စခန်း အသုံးပြုထားမှု ပမာဏ (`X / max_lots`)
  - [ ] ဝန်ထမ်း အသုံးပြုထားမှု ပမာဏ (`Y / max_staff`)
- [ ] ပက်ကေ့ဂျ် အဆင့်မြှင့်ခြင်း / သက်တမ်းတိုးခြင်း
  - [ ] ရရှိနိုင်သော ပက်ကေ့ဂျ်များ ပြသခြင်း (Basic, Pro, Enterprise)
  - [ ] "ဝယ်ယူမည်" / "သက်တမ်းတိုးမည်" ခလုတ်
  - [ ] ဒစ်ဂျစ်တယ် ပိုက်ဆံအိတ် ငွေပေးချေမှု စနစ်သို့ ညွှန်းပို့ပေးခြင်း

### ၂.၈ ပိုင်ရှင်၏ ဒစ်ဂျစ်တယ် ပိုက်ဆံအိတ် ပြင်ဆင်ခြင်း (/owner/wallet)
- [ ] ငွေလက်ခံမည့် ပိုက်ဆံအိတ် ဆက်တင်
  - [ ] ပိုင်ရှင်၏ Digital Wallet API Key (`api_key`) ဖြည့်သွင်းခြင်း
  - [ ] ပိုက်ဆံအိတ် ဖုန်းနံပါတ် ဖြည့်သွင်းခြင်း
  - [ ] ချိတ်ဆက်မှု စမ်းသပ်ခြင်း ခလုတ်
  - [ ] စခန်းများမှ ယာဉ်ရပ်နားခ ငွေများ ဤပိုက်ဆံအိတ်သို့ တိုက်ရိုက် ရောက်ရှိမည့် သတိပေးချက်

## ၃။ ယာဉ်ရပ်နားစခန်း ဝန်ထမ်း လုပ်ဆောင်ချက်များ - Staff Dashboard (smart-parking-management)

### ၃.၁ အကောင့်ဝင်ခြင်းနှင့် တာဝန်ကျ စခန်း အချက်အလက်
- [ ] အကောင့်ဝင်ရောက်ခြင်း (Login - `STAFF` ရာထူး)
- [ ] တာဝန်ကျ ယာဉ်ရပ်နားစခန်း အချက်အလက် ရယူခြင်း
- [ ] ဒက်ရှ်ဘုတ် သို့ ရောက်ရှိခြင်း (`/staff/dashboard`)

### ၃.၂ ဝန်ထမ်း ဒက်ရှ်ဘုတ် စာမျက်နှာ (/staff/dashboard)
- [ ] တာဝန်ကျ စခန်း ခေါင်းစဉ် (စခန်းအမည်၊ တည်နေရာ၊ အဆင့်၊ တစ်နာရီ ကျသင့်ငွေ)
- [ ] ဂျူတီချိန် အချက်အလက် ကတ်များ (Shift Summary)
  - [ ] ယနေ့ ဝင်ရောက်ခဲ့သော ယာဉ်အရေအတွက် (Check-ins Today)
  - [ ] ယနေ့ ထွက်ခွာခဲ့သော ယာဉ်အရေအတွက် (Check-outs Today)
  - [ ] လက်ရှိ ရပ်နားထားသော ယာဉ်အရေအတွက် (Occupied Slots)
  - [ ] ယနေ့ ရရှိသော ငွေသား စုစုပေါင်း (Cash Collected in MMK)
  - [ ] ယနေ့ ရရှိသော ဒစ်ဂျစ်တယ် ငွေချေမှု စုစုပေါင်း (Digital Payments in MMK)
- [ ] အမြန် လုပ်ဆောင်ချက် ခလုတ်များ
  - [ ] ယာဉ်အဝင် လက်ခံရန် → `/staff/check-in`
  - [ ] ယာဉ်အထွက် ငွေရှင်းရန် → `/staff/check-out`
  - [ ] နေရာများ အခြေအနေ ကြည့်ရန် → `/staff/slots`

### ၃.၃ ယာဉ်အဝင် လက်ခံခြင်း (Gate Check-In / Entry)
- [ ] ယာဉ်အဝင် ဖြည့်သွင်းလွှာ
  - [ ] ယာဉ်အမှတ် (ယာဉ်လိုင်စင်နံပါတ်) ဖြည့်သွင်းခြင်း
  - [ ] အထပ် ရွေးချယ်ခြင်း
  - [ ] လွတ်လပ်နေသော ရပ်နားနေရာ ရွေးချယ်ခြင်း (Available Slots သာ ရွေးချယ်နိုင်မည်)
- [ ] အဝင် အတည်ပြုခြင်း
  - [ ] အတည်ပြုပါက ရပ်နားမှု စတင်ချိန် အလိုအလျောက် မှတ်တမ်းတင်ခြင်း
  - [ ] ရွေးချယ်လိုက်သော နေရာအား `OCCUPIED` (ပြည့်) သို့ ပြောင်းလဲခြင်း
  - [ ] ယာဉ်အဝင် လက်မှတ်/ပြေစာ ထုတ်ပေးခြင်း

### ၃.၄ ယာဉ်အထွက် ငွေရှင်းခြင်း (Gate Check-Out / Exit)
- [ ] ယာဉ်အထွက် ရှာဖွေခြင်း
  - [ ] ယာဉ်အမှတ် သို့မဟုတ် ရပ်နားနေရာ နံပါတ်ဖြင့် ရှာဖွေခြင်း
- [ ] ငွေတွက်ချက်သည့် စာမျက်နှာ
  - [ ] အဝင်ချိန်၊ အထွက်ချိန်၊ စုစုပေါင်း ကြာမြင့်ချိန် တွက်ချက်ပြသခြင်း
  - [ ] ကျသင့်ငွေ အလိုအလျောက် တွက်ချက်ပေးခြင်း (`ကြာမြင့်ချိန် × တစ်နာရီ နှုန်းထား`)
  - [ ] ငွေချေစနစ် ရွေးချယ်ခြင်း - ငွေသား (Cash) သို့မဟုတ် ဒစ်ဂျစ်တယ် ပိုက်ဆံအိတ် (Digital Wallet)
- [ ] ယာဉ်အထွက် ပြီးမြောက်ခြင်း
  - [ ] ငွေချေမှု အခြေအနေ ပြီးမြောက်ကြောင်း မှတ်တမ်းတင်ခြင်း (`COMPLETED`)
  - [ ] ယာဉ်ရပ်နားမှု စေရှင်အား ပြီးဆုံးစေခြင်း (`FINISHED`)
  - [ ] ရပ်နားခဲ့သော နေရာအား `AVAILABLE` (လွတ်) သို့ ပြန်လည်ပြောင်းလဲခြင်း
  - [ ] ယာဉ်အထွက် ပြေစာ ထုတ်ပေးခြင်း

### ၃.၅ လက်ရှိ နေရာများ အခြေအနေ ပြဇယား (/staff/slots)
- [ ] စခန်းအလိုက် နေရာများ မြင်ကွင်း (Live Slot Grid)
  - [ ] အထပ်အလိုက် ရွေးချယ် ကြည့်ရှုနိုင်ခြင်း
  - [ ] အရောင်ပြစနစ်ဖြင့် နေရာများ အခြေအနေ ကြည့်ရှုနိုင်ခြင်း:
    - 🟢 အစိမ်းရောင်: `AVAILABLE` (လွတ်)
    - 🔴 အနီရောင်: `OCCUPIED` (ပြည့်)
  - [ ] အပိုင်းအခြားအလိုက် စုစည်းပြသခြင်း (Section A, Section B)
- [ ] နေရာ အခြေအနေ ကိုယ်တိုင် ပြောင်းလဲခြင်း (Manual Override)
  - [ ] ပြုပြင်ထိန်းသိမ်းမှု သို့မဟုတ် အရေးပေါ် အခြေအနေများအတွက် နေရာ၏ အခြေအနေအား ကိုယ်တိုင် နှိပ်၍ ပြောင်းလဲနိုင်ခြင်း (`AVAILABLE` ↔ `OCCUPIED`)

### ၃.၆ လက်ရှိ ရပ်နားထားသော ယာဉ်များ စာရင်း (/staff/sessions)
- [ ] ရပ်နားထားဆဲ ယာဉ်များ စာရင်း
  - [ ] စခန်းတွင် လက်ရှိ ရပ်နားထားသော ယာဉ်များအားလုံး ဇယား (ယာဉ်အမှတ်၊ အထပ်နှင့်နေရာ၊ အဝင်ချိန်၊ ရပ်နားထားသည့် ကြာမြင့်ချိန်၊ ကျသင့်နေသည့် ငွေပမာဏ)
  - [ ] ယာဉ်အမှတ်ဖြင့် အမြန် ရှာဖွေနိုင်ခြင်း

## ၄။ သုံးစွဲသူ မော်တော်ယာဉ်မောင်း လုပ်ဆောင်ချက်များ - Customer App (smart-parking-customer)

### ၄.၁ အကောင့်ဖွင့်ခြင်းနှင့် လုံခြုံရေး စနစ်

  - [ ] အချက်အလက်များ ဖြည့်သွင်းခြင်း (အမည်၊ အီးမေးလ်၊ ဖုန်းနံပါတ် `09...`၊ စကားဝှက်နှင့် အတည်ပြု စကားဝှက်)
  - [ ] အကောင့်ဖန်တီးပြီးပါက အီးမေးလ် OTP အတည်ပြု စာမျက်နှာသို့ ရောက်ရှိခြင်း
- [ ] အီးမေးလ် အတည်ပြုခြင်း (/verify-email)
  - [ ] ဂဏန်း ၆ လုံးပါ OTP ကုတ် ဖြည့်သွင်းခြင်း
  - [ ] မမှန်ကန်သော သို့မဟုတ် သက်တမ်းကုန်သွားသော OTP အမှားပြစာတို
  - [ ] OTP ကုတ် ပြန်လည်တောင်းဆိုနိုင်ခြင်း (Resend OTP with countdown timer)
- [ ] အကောင့်ဝင်ခြင်း (/login)
  - [ ] အီးမေးလ်နှင့် စကားဝှက်ဖြင့် အကောင့်ဝင်ခြင်း
  - [ ] အကောင့်ဝင်ပြီးပါက သုံးစွဲသူ ဒက်ရှ်ဘုတ် (/) သို့ ရောက်ရှိခြင်း
- [ ] စကားဝှက် မေ့သွားပါက ပြန်လည်ယူခြင်း (/forgot-password)
  - [ ] အီးမေးလ် ဖြည့်သွင်း၍ OTP ဖြင့် စကားဝှက် အသစ် ပြန်လည်သတ်မှတ်ခြင်း

### ၄.၂ သုံးစွဲသူ ဒက်ရှ်ဘုတ်နှင့် မြေပုံစနစ် (/)
- [ ] မြေပုံစနစ် (Interactive GPS Map)
  - [ ] ရန်ကုန်မြို့ အခြေစိုက် တည်နေရာ မြေပုံ ပြသခြင်း (Leaflet Map)
  - [ ] ယာဉ်ရပ်နားစခန်းများ၏ တည်နေရာ ပင်အပ် (Pin) များ ပြသခြင်း
  - [ ] ပင်အပ်အား နှိပ်ပါက စခန်း၏ အချက်အလက် အကျဉ်း ပေါ့ပ်အပ် ပြသခြင်း
- [ ] ရှာဖွေမှုနှင့် စစ်ထုတ်မှုများ
  - [ ] စခန်းအမည် သို့မဟုတ် မြို့နယ်အလိုက် ရှာဖွေနိုင်ခြင်း (Search)
  - [ ] စခန်း အမျိုးအစားအလိုက် စစ်ထုတ်ခြင်း (`ALL`, `PUBLIC`, `PRIVATE`)
- [ ] ယာဉ်ရပ်နားစခန်း ကတ်များ စာရင်း
  - [ ] စခန်းအမည်၊ အမျိုးအစား၊ တစ်နာရီ ကျသင့်ငွေ၊ စုစုပေါင်း နေရာ၊ ရရှိနိုင်သော နေရာ အရေအတွက်
  - [ ] လက်ရှိ တည်နေရာမှ ကွာဝေးသည့် အကွာအဝေး
  - [ ] "3D မြင်ကွင်း ကြည့်မည်" ခလုတ် → `/parking/:id/3d`
  - [ ] "Google Maps ဖြင့် သွားမည်" လမ်းကြောင်းပြ လင့်ခ်

### ၄.၃ 3D/2D ယာဉ်ရပ်နားနေရာများ ကြည့်ရှုသည့် စနစ် (/parking/:id/3d)

  - [ ] တိုက်ရိုက် နေရာ လွတ်/မလွတ် ပြသခြင်း (🟢 အစိမ်း = လွတ်၊ 🔴 အနီ = ပြည့်)

#### Session Booking Rules (ယာဉ်ရပ်နားချိန်း ဘွတ်ကင် စည်းကမ်းများ)

သုံးစွဲသူများ ယာဉ်ရပ်နားချိန်း ဘွတ်ကင် ပြုလုပ်ပါက အောက်ပါ စည်းကမ်းများ အလိုအလျောက် စစ်ဆေးသည် —

**အချိန် စစ်ဆေးချက်များ (Time Validation)**
- [ ] **စတင်ချိန် ဆောင်ရွက်နိုင်မှု** — Start time သည် လက်ရှိ အချိန်ထက် ရှေ့ဖြစ်ရမည် (အနာဂတ်ချိန်သာ ဘွတ်ကင်ပြုလုပ်နိုင်သည်)
- [ ] **ကုန်ဆုံးချိန် စစ်ဆေးမှု** — End time သည် Start time ထက် နောက်ကျရမည်

**ယာဉ် တစ်စီး အချက်အလက် စစ်ဆေးချက်များ (Car Conflict Check)**
- [ ] ဘွတ်ကင်ပြုလုပ်မည့် ယာဉ်သည် ကိုယ်ပိုင် ယာဉ်ဖြစ်ရမည်
- [ ] ထိုယာဉ်အတွက် လက်ရှိ ACTIVE ဘွတ်ကင် တစ်ခုနှင့် ချိန်အကျ ဆိုပါက ဘွတ်ကင် ပယ်ချသည်
  - ဥပမာ — ယာဉ်သည် `10:00–14:00` ဘွတ်ကင်ထားပြီး `12:00–16:00` ထပ်မံ ဘွတ်ကင်ဖွင့်ပါက ပယ်ချသည်

**နေရာ တစ်ခု Buffer စစ်ဆေးချက်များ (Slot 2-Hour Buffer Rule)**
- [ ] **2-နာရီ ကြားချိန် (Buffer)** — ယာဉ်ရပ်နားနေရာ တစ်ခုတွင် ACTIVE ဘွတ်ကင် ရှိပါက ထိုဘွတ်ကင် **မစတင်မီ 2 နာရီ** နှင့် **ပြီးဆုံးပြီး 2 နာရီ** အတွင်း ဘွတ်ကင် ဖွင့်၍မရ
  - ဥပမာ — Slot A တွင် `10:00–12:00` ဘွတ်ကင် ရှိသည်
    - ❌ `08:30–11:00` → မရ (2-နာရီ ကြားချိန် မပြည့်)
    - ❌ `12:30–14:00` → မရ (2-နာရီ ကြားချိန် မပြည့်)
    - ✅ `07:59 မတိုင်မီ` ကုန်ဆုံးသော ဘွတ်ကင် → ရ (2-နာရီ ကြားချိန် ပြည့်သည်)
    - ✅ `14:01 နောက်မှ` စတင်သော ဘွတ်ကင် → ရ (2-နာရီ ကြားချိန် ပြည့်သည်)
- [ ] Pending (ငွေချေမပြီးသော) ဘွတ်ကင်များတွင်လည်း ထိုနည်းတူ 2-နာရီ Buffer စစ်ဆေးသည်

**ကျသင့်ငွေ တွက်ချက်မှု (Fee Calculation)**
- [ ] နာရီနှုန်းထားသည် ယာဉ်ရပ်နားစခန်း (`rate_per_hour`) မှ ယူသည်၊ မရှိပါက စနစ် Default နှုန်းထားကို သုံးသည်
- [ ] ကျသင့်ငွေ = `(ကြာမြင့်ချိန် minutes ÷ 60) × rate_per_hour` (မိနစ်တိုင်း အပေါ်သို့ အနီးဆုံး မိနစ်သို့ Round up)
  - ဥပမာ — `90 မိနစ် ÷ 60 × 1,000 MMK = 1,500 MMK`
  - ဥပမာ — `61 မိနစ်` ဆိုပါက `62 မိနစ်` ဟု Round up ၍ `(62÷60) × 1,000 ≈ 1,033 MMK`



### ၄.၄ ပိုင်ဆိုင်သော မော်တော်ယာဉ်များ စီမံခန့်ခွဲခြင်း (/cars)

### ၄.၅ လက်ရှိ ယာဉ်ရပ်နားမှုနှင့် ကုန်ကျငွေ ကြည့်ရှုခြင်း (/sessions)

  - [ ] ရပ်နားထားသည့် ကြာမြင့်ချိန် တိုက်ရိုက် နာရီ/မိနစ်/စက္ကန့် ပြသခြင်း
  - [ ] ကျသင့်နေသည့် ငွေပမာဏ တိုက်ရိုက် တိုးတက်ပြသခြင်း (MMK Live Timer)
- [ ] ယာဉ်ရပ်နားခဲ့မှု မှတ်တမ်းများ (Session History Tab)
  - [ ] ယခင် ရပ်နားခဲ့ဖူးသော စာရင်းများ၊ အဝင်/အထွက် အချိန်၊ ကျသင့်ငွေ၊ ငွေချေစနစ်
  - [ ] ဒစ်ဂျစ်တယ် ငွေချေမှု ပြေစာ ကြည့်ရှုနိုင်ခြင်း

- [ ] ဒစ်ဂျစ်တယ် ပိုက်ဆံအိတ် ငွေချေမှု စာမျက်နှာ
  - [ ] ဒစ်ဂျစ်တယ် ပိုက်ဆံအိတ် စနစ် (`digital-wallet-backend-api.up.railway.app`) သို့ ရောက်ရှိခြင်း
  - [ ] ပိုက်ဆံအိတ် ဖုန်းနံပါတ်နှင့် OTP ကုတ် ဖြည့်သွင်းခြင်း

  - [ ] ငွေချေမှု အောင်မြင်/မအောင်မြင် အခြေအနေ ဘေနာ ပြသခြင်း
  - [ ] လုပ်ငန်းစဉ် အမှတ် (`PP...`) နှင့် ဒစ်ဂျစ်တယ် ပြေစာ အကျဉ်း ပြသခြင်း

## ၅။ နောက်ကွယ် API လုပ်ဆောင်ချက်များ - Backend API (smart-parking-api)

### ၅.၁ အကောင့်စနစ်နှင့် လုံခြုံရေး API (/api/v1/auth)
- [ ] `POST /auth/register` — သုံးစွဲသူ အကောင့်သစ် ဖွင့်ခြင်း
- [ ] `POST /auth/verify-otp` — အီးမေးလ် OTP အတည်ပြုခြင်း
- [ ] `POST /auth/resend-otp` — OTP ကုတ် ထပ်မံတောင်းဆိုခြင်း
- [ ] `POST /auth/login` — အကောင့်ဝင်ခြင်း (JWT Access/Refresh Tokens ထုတ်ပေးခြင်း)
- [ ] `POST /auth/forgot-password` — စကားဝှက် မေ့သွားပါက OTP ပို့ဆောင်ခြင်း
- [ ] `POST /auth/reset-password` — OTP ဖြင့် စကားဝှက် အသစ် ပြောင်းလဲခြင်း
- [ ] `GET /auth/me` — လက်ရှိ သုံးစွဲသူ၏ ပရိုဖိုင်နှင့် လုပ်ပိုင်ခွင့်များ ရယူခြင်း

### ၅.၂ သုံးစွဲသူများ စီမံခန့်ခွဲသည့် API (/api/v1/users)
- [ ] `GET /users` — သုံးစွဲသူများ စာရင်း ရယူခြင်း (ရာထူးအလိုက် စစ်ထုတ်ခြင်း၊ ရှာဖွေခြင်း၊ စာမျက်နှာ ခွဲခြင်း)
- [ ] `GET /users/{id}` — သုံးစွဲသူ တစ်ဦး၏ အသေးစိတ် အချက်အလက် ရယူခြင်း
- [ ] `PATCH /users/{id}/status` — သုံးစွဲသူ အကောင့်အား အသုံးပြုခွင့် ပိတ်/ဖွင့် ပြုလုပ်ခြင်း

### ၅.၃ ဝန်ဆောင်မှု ပက်ကေ့ဂျ် API (/api/v1/packages)
- [ ] `GET /packages` — အသုံးပြုနိုင်သော ဝန်ဆောင်မှု ပက်ကေ့ဂျ်များ စာရင်း ရယူခြင်း
- [ ] `POST /packages` — ပက်ကေ့ဂျ်အသစ် ဖန်တီးခြင်း (Admin သာ)
- [ ] `PUT /packages/{id}` — ပက်ကေ့ဂျ် စျေးနှုန်းနှင့် ကန့်သတ်ချက်များ ပြင်ဆင်ခြင်း (Admin သာ)
- [ ] `DELETE /packages/{id}` — ပက်ကေ့ဂျ် ပိတ်သိမ်းခြင်း (Admin သာ)

### ၅.၄ ဝန်ဆောင်မှု သက်တမ်း API (/api/v1/subscriptions)
- [ ] `GET /subscriptions/admin/all` — ပိုင်ရှင်များ၏ ဝန်ဆောင်မှု သက်တမ်းများ စာရင်း ရယူခြင်း (Admin သာ)
- [ ] `POST /subscriptions/subscribe` — ပိုင်ရှင်မှ ပက်ကေ့ဂျ် ဝယ်ယူမှု စတင်ခြင်း
- [ ] `POST /subscriptions/{id}/activate` — ဝန်ဆောင်မှု သက်တမ်းအား ကိုယ်တိုင် အတည်ပြုပေးခြင်း (Admin Override)

### ၅.၅ ယာဉ်ရပ်နားစခန်းနှင့် ဒီဇိုင်း API (/api/v1/parking-lots, /parking-floors, /parking-slots)
- [ ] `GET /parking-lots` — ပိုင်ရှင်၏ ယာဉ်ရပ်နားစခန်းများ စာရင်း ရယူခြင်း
- [ ] `POST /parking-lots` — ယာဉ်ရပ်နားစခန်းအသစ် ဖန်တီးခြင်း (ပက်ကေ့ဂျ် ကန့်သတ်ချက် `max_lots` စစ်ဆေးသည်)
- [ ] `PUT /parking-lots/{id}` — စခန်း အချက်အလက်နှင့် နှုန်းထားများ ပြင်ဆင်ခြင်း
- [ ] `GET /parking-lots/customer/search` — သုံးစွဲသူများအတွက် အနီးရှိ စခန်းများအား တည်နေရာနှင့်တကွ ရှာဖွေပေးခြင်း
- [ ] `POST /parking-floors` — စခန်းသို့ အထပ်အသစ် ထည့်သွင်းခြင်း
- [ ] `POST /parking-slots` — အထပ်သို့ နေရာအသစ် ထည့်သွင်းခြင်း (GPS Coordinates ပါဝင်သည်)
- [ ] `PATCH /parking-slots/{id}/status` — နေရာ၏ အခြေအနေအား ပြောင်းလဲခြင်း (`AVAILABLE` / `OCCUPIED`)
- [ ] `GET /parking-lots/{id}/layout` — စခန်း၏ အထပ်နှင့် နေရာများ 2D/3D ဒီဇိုင်း အချက်အလက် ရယူခြင်း

### ၅.၆ ဝန်ထမ်း စီမံခန့်ခွဲမှု API (/api/v1/parking-staff)

- [ ] `POST /parking-staff` — ဝန်ထမ်းအကောင့်သစ် ဖန်တီး၍ စခန်းသို့ တာဝန်ပေးခြင်း (ပက်ကေ့ဂျ် ကန့်သတ်ချက် `max_staff` စစ်ဆေးသည်)
- [ ] `DELETE /parking-staff/{id}` — ဝန်ထမ်း အကောင့်အား ပယ်ဖျက်ခြင်း

### ၅.၇ သုံးစွဲသူ မော်တော်ယာဉ် API (/api/v1/cars)

- [ ] `DELETE /cars/{id}` — မှတ်ပုံတင်ထားသော ယာဉ်အား ပယ်ဖျက်ခြင်း

### ၅.၈ ယာဉ်ရပ်နားမှု စေရှင် API (/api/v1/parking-sessions)
- [ ] `POST /parking-sessions/check-in` — ယာဉ်အဝင် လက်ခံခြင်း (စေရှင် စတင်သည်၊ နေရာအား ပြည့် သို့ ပြောင်းသည်)
- [ ] `POST /parking-sessions/check-out` — ယာဉ်အထွက် ငွေရှင်းခြင်း (ကျသင့်ငွေ တွက်ချက်သည်၊ နေရာအား လွတ် သို့ ပြောင်းသည်)
- [ ] `GET /parking-sessions/active` — တာဝန်ကျ စခန်း၏ လက်ရှိ ရပ်နားထားသော ယာဉ်များ စာရင်း ရယူခြင်း (Staff)
- [ ] `GET /parking-sessions/customer/active` — သုံးစွဲသူ၏ လက်ရှိ ရပ်နားထားသော ယာဉ် စေရှင် အချက်အလက် ရယူခြင်း
- [ ] `GET /parking-sessions/customer/history` — သုံးစွဲသူ၏ ယခင် ရပ်နားခဲ့သော စေရှင် မှတ်တမ်းများ ရယူခြင်း

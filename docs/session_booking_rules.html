3. Slot Buffer Rule — 2-Hour Gap Required

After any booking on a slot, 2 hours must pass before the next booking can start. Same gap required before a booking begins.

4. Fee Calculation

Duration is measured in minutes and rounded up to the nearest minute (ceiling). Rate comes from the parking lot; falls back to system default if not set.

Fee = ⌈ duration_minutes ⌉ ÷ 60 × rate_per_hour

Example 1 — Exact hours

Duration: 90 min
Rate: 1,000 MMK/hr
= 90 ÷ 60 × 1,000
= 1,500 MMK

Example 2 — Fractional (round up)

Duration: 61 min → ⌈61⌉ = 62 min
Rate: 1,000 MMK/hr
= 62 ÷ 60 × 1,000
≈ 1,033 MMK
